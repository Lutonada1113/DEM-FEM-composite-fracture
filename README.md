# DEM-FEM for anisotropic phase-field fracture in composites

This folder contains the numerical implementation, input meshes, and archived simulation results for a staggered deep energy–finite element method for composite fracture. A neural displacement approximation is coupled to a finite-element damage solve. The five benchmark families also include conventional finite-element displacement reference solvers.

The distribution contains computation and numerical data. Figure-generation scripts, manuscript and presentation builders, images, notebooks from unrelated projects, duplicate ZIP archives, and per-step checkpoint snapshots are excluded.

## Contents

| Path | Purpose |
| --- | --- |
| `dsolve.py` | Shared neural network, material, energy, history-field, and phase-field utilities |
| `examples/verification/` | Plate with spatially varying fiber orientations |
| `examples/SENT1/` | Off-axis single-edge-notched tension and anisotropy-parameter cases |
| `examples/circlehole1/` | Open-hole tension and length-scale, mesh, and increment studies |
| `examples/hole/` | Equal-area circular, square, and triangular openings |
| `examples/interface/` | Finite-width weak material band and additional archived band properties |
| `results/` | Original field, force, timing CSVs and latest available checkpoints |
| `run_case.py` | Isolated numerical launcher; creates a new directory under `runs/` |
| `load_results.py` | Nodal-result reader with last-record handling for resumed runs |
| `check_env.py` | Dependency, mesh-reading, and automatic-differentiation check |
| `docs/` | Data format, provenance, and preparation notes |

Each benchmark has `main.py` for DEM-FEM and `main_fem.py` for the finite-element reference. The numerical classes and helper functions are retained from the research implementation; automatic plotting has been removed. Archived results are stored separately from executable examples, so a new run does not resume from or overwrite the reference data.

## Install and check

Python 3.10 or later is needed. Create a Python environment and install the dependencies:

```bash
python -m pip install -r requirements.txt
python check_env.py
```

For CUDA-enabled PyTorch, use the installation command for your platform from the [official PyTorch installation selector](https://pytorch.org/get-started/locally/). The neural displacement solve can use CUDA. The damage solve and the supplied Python FEM reference drivers use NumPy/SciPy sparse operations on the CPU. This distribution was smoke-tested on CPU; exact package versions and validation scope are recorded in `validation.json`.

## Run a case

Run commands from this folder. Arguments after `--` are passed to the benchmark driver. `--steps` limits the number of increments executed; it does not redefine the driver's total loading schedule.

```bash
# Quick startup check: coarse open-hole mesh, one increment, two training epochs.
# This intentionally short run is not a converged fracture prediction.
python run_case.py circlehole1 --solver dem-fem --seed 7 --threads 1 -- --angle 30 --mesh 2 --no-effective-gc --steps 1 --epochs 2 --no-stag

# Corresponding conventional FEM startup check.
python run_case.py circlehole1 --solver fem --threads 1 -- --angle 30 --mesh 2 --steps 1

# Standard open-hole DEM-FEM run with the nominal fracture-energy parameter.
python run_case.py circlehole1 --solver dem-fem -- --angle 30 --mesh 0.15 --no-effective-gc --device cuda

# Inspect the original solver's options.
python run_case.py SENT1 --solver dem-fem -- --help

# Weak-band case, using the archived-result mesh interface_crack.msh.
python run_case.py interface --solver dem-fem -- --case weak --device cpu
```

A new run contains copies of the numerical drivers and required inputs, plus `run_config.json` recording arguments, numerical constants, environment, and optional seed. Existing run names are rejected. To resume, invoke the copied driver inside that run directly, using its original options. Numerical checkpoints and step snapshots generated by future calculations remain inside that run.

Numerical constants not exposed by the original drivers can be supplied explicitly:

```bash
# Length scale, with standard open-hole input and load schedule.
python run_case.py circlehole1 --set L=0.2 -- --angle 30 --no-effective-gc

# Anisotropy parameter study on the supplied refined SENT45 mesh.
python run_case.py SENT1 --set BETA=10 --replace-mesh SENT45/SENT45.msh=SENT45beta.msh -- --angle 45

# Plan a command without creating files or loading numerical libraries.
python run_case.py verification --dry-run -- --mesh 1 --tensor A1
```

These are explicit new calculations with the selected settings. The available source does not retain every historical run's full parameter record. Consult `docs/reproducibility.md` before interpreting a new calculation as an exact regeneration of an archived result.

## Read archived data

```bash
python load_results.py results/circlehole1/alpha30/results_alpha30_A1.csv
```

```python
from load_results import load_step

fields = load_step("results/interface/weak/results_weak.csv")
xy = fields["coordinates"]
u = fields["displacement"]
d = fields["damage"]
```

`results/field_catalog.json` records saved steps, node counts, duplicate records, damage ranges, and matching supplied meshes for all 81 nodal field CSVs. `results/file_manifest.csv` records original paths, sizes, and SHA-256 digests of all 247 archived numerical files. Data have not been silently cleaned or recalculated.

## Research provenance and release status

The associated work is *A staggered deep energy–finite element method for anisotropic phase-field fracture in fiber-reinforced composites*. Constitutive and phase-field ingredients follow the research sources cited in that work, including Yu et al., *Fatigue & Fracture of Engineering Materials & Structures* 47 (2024), 4176–4195, DOI: 10.1111/ffe.14429.

This is a prepared release folder. An open-source license has not yet been selected by the authors; no license terms have been assigned during file organization.
